# Qlab Studio — Онлайн Калькулятор и База Заказов 3D-печати

Профессиональная система расчета себестоимости, ценообразования и управления заказами 3D-печати (Bambu Lab AMS / FDM).

## 🚀 Доступ онлайн
После включения **GitHub Pages** в настройках репозитория проект доступен по постоянной ссылке:
👉 **https://qazaqlab.github.io/qlab_calc/**

Сайт полностью адаптивен и работает на смартфонах, планшетах, ноутбуках и ПК.

---

## ⚡ Возможности
1. **Калькулятор стоимости и прибыли (Формула Qlab):**
   - Расчет тарифа клиенту: `(Вес × ТарифПластика) + (Время × ТарифВремени) + Моделирование/Подготовка`.
   - Точный учет физической себестоимости: сырье, электроэнергия (30.15 ₸/кВт·ч), амортизация принтера, 10% брак/риски.
   - Автоматический расчет маржинальности (%).
   - Учет тиража: динамическое масштабирование веса, времени и затрат при печати нескольких штук.

2. **Склад пластика (Катушки AMS):**
   - Добавление катушек с указанием бренда, типа (PLA, PETG, ABS, TPU), цвета, веса и закупочной цены.
   - Живой мониторинг остатка: оповещение при нехватке пластика на заказ.
   - Автоматическое списание граммовки со склада при оформлении заказа.

3. **Синхронизация между устройствами (ПК, Телефон, Планшет):**
   - **Облако Firebase:** мгновенное обновление базы заказов и склада в реальном времени (WebSockets) на всех устройствах.
   - **QR-код для быстрого входа:** отсканируйте камерой смартфона для автоматического подключения к базе.
   - **Локальный Wi-Fi сервер:** возможность работы в студии без интернета через локальную сеть (`http://192.168.10.x:3000`).
   - **Автономный оффлайн-режим:** локальное сохранение в `IndexedDB` и `localStorage`.

4. **История заказов и CRM:**
   - Данные клиента: имя, телефон/WhatsApp, дедлайн, статус выполнения.
   - Фильтрация заказов («В очереди», «В печати», «Готов», «Выдан»).
   - Быстрый переход в WhatsApp для связи с клиентом.

5. **Финансовая аналитика и Календарь:**
   - Выручка, себестоимость, чистая прибыль, средний чек, расход пластика.
   - Графики рентабельности и структуры затрат.
   - Производственный календарь с дедлайнами по заказам.

## 💻 Локальный запуск
Для работы по локальной сети без интернета:
```bash
node server.js
```
Или запустите файл `Запустить Qlab Studio.bat` на рабочем столе.
- ПК / Ноутбук: `http://localhost:3000`
- Смартфон / Планшет в Wi-Fi сети: `http://<IP_вашего_ПК>:3000`
