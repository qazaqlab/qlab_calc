Supabase — рекомендуемый облачный бэкенд для Qlab Studio. Вход в 1 клик через ваш GitHub qazaqlab, мгновенная синхронизация через WebSockets на телефонах, ноутбуках и планшетах. Бесплатно навсегда.
SQL скопирован в буфер! Вставьте его в раздел SQL Editor на supabase.com и нажмите Run.
Как включить за 1 минуту:
1. Откройте supabase.com и нажмите «Start your project» → «Continue with GitHub» (вход в 1 клик).
2. Нажмите «New project» (назовите qlab-studio).
3. Слева в меню откройте SQL Editor → вставьте скопированный код и нажмите Run.
4. В Project Settings → API скопируйте Project URL и anon key и вставьте в поля выше.

Google Firebase обеспечивает моментальную синхронизацию за 0.1 секунды между любым количеством телефонов, ноутбуков и планшетов из любой точки мира. Бесплатно навсегда.
Сохраняется локально в браузере
Как включить за 1 минуту:
1. Откройте console.firebase.google.com.
2. Создайте проект (например qlab-studio).
3. Включите Firestore Database (тестовый режим).
4. В настройках проекта (⚙️) скопируйте firebaseConfig и вставьте в поле выше.

Автономный Wi-Fi сервер Qlab Studio

На вашем рабочем столе создан файл: Запустить Qlab Studio.bat.

Адрес для телефона / планшета в локальной сети:

Дважды кликните по файлу — сервер запустится, и любой телефон в вашей сети сможет работать с единой базой.
